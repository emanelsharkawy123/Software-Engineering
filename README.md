# University Rooms & Labs Booking and Scheduling System

## 1. Project Overview
This project is a Java desktop application designed to manage university classrooms, lecture halls, and laboratories. It helps organize academic schedules, manage room bookings, and prevent scheduling conflicts.

## 2. Main Objectives
- Manage classrooms, lecture halls, and laboratories.
- Create and manage room bookings.
- Prevent conflicts between rooms, instructors, and student groups.
- Support recurring lectures and laboratory sessions.
- Display personalized timetables.
- Generate basic room utilization reports.

## 3. Main Users
- Administrator
- Doctor / Faculty Member
- Lab Supervisor
- Student

## 4. Technology Stack

- User Interface: JavaFX (proposed)
